# MySupreme — Concept B (redesigned live site)

Prototype of mysupreme.ca with a full UI/UX redesign on one design system: same pages, routes and data as the live
site, plus a clickable checkout. What changed and why: `CHANGES.md`.
Build guide: `CLAUDE.md`. Dummy data: `data/*.json` (snapshot made once by `npm run seed`).

    npm install
    npm run build && npm start   # http://localhost:5180  (or `npm run dev` for hot reload)
